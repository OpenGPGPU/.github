# OpenGPGPU organization profile

This repository maintains the public profile for the
[OpenGPGPU](https://github.com/OpenGPGPU) organization.

The profile content lives in [`profile/README.md`](profile/README.md). Open it
to learn about the RISC-V SIMT GPU and its full-system simulation and EDA
toolchain.

**Current repositories:** gpu (Scala/Chisel), FlashSim (Python), arti (Python), chipagent (Python)
