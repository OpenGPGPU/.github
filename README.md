# OpenGPGPU organization profile

This repository maintains the public profile for the
[OpenGPGPU](https://github.com/OpenGPGPU) organization.

The profile content lives in [`profile/README.md`](profile/README.md). It
describes the RISC-V SIMT GPU, the 640×480 Weston desktop it currently draws
under QEMU, and the compiler, simulation, and EDA repositories around it.

**Current repositories:** gpu (Scala/Chisel), llvm-project (C++, branch `opengpu`), FlashSim (Python/C++), arti (Python), chipagent (Python)
